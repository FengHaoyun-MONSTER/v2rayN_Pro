# 工作区背景与透明度设计

## 功能

- 在设置窗口“外观”页选择或移除工作区背景图片。
- 支持 JPG、PNG、BMP，图片使用 `UniformToFill` 覆盖工作区。
- 背景透明度范围为 `0%` 到 `100%`，默认 `30%`。
- 首页和代理页共享同一个缓存后的背景对象，页面切换不重新解码。

## 文件保存

保存设置时将图片复制为 `guiConfigs/workspace-background.<ext>`，配置只记录文件名。程序不依赖用户选择的原始文件位置，整个 v2rayN 目录迁移后背景仍然有效。

更换或移除背景后，只清理 `guiConfigs` 顶层中由本功能管理的 `workspace-background.*` 文件，不处理其他文件。

## 渲染与性能

- 使用 `BitmapCacheOption.OnLoad` 一次性解码并释放文件句柄。
- 解码宽度限制为 2560 像素，避免超大图片产生过高内存占用。
- 解码后的 `BitmapImage` 冻结并由首页、代理页共同使用。
- 不使用实时模糊效果。
- 首页使用轻量主题遮罩；代理页使用更强主题遮罩，优先保证表格和日志可读性。
- 顶部导航和底部状态栏保持实色。

## 失败处理

- 文件不存在、扩展名不支持或复制失败时不保存设置，并显示错误提示。
- 图片解码失败时记录日志并回退到主题纯色背景，不影响代理功能。
# GIF 动态背景扩展

- 设置页支持选择 JPG、JPEG、PNG、BMP 和 GIF 文件。
- GIF 使用 `XamlAnimatedGif` 逐帧即时解码，首页与代理页共享同一个背景控件，切换页面不会重新加载或重新开始动画。
- GIF 强制循环播放；窗口最小化或隐藏到托盘时暂停，窗口恢复显示后从当前帧继续播放。
- GIF 文件限制为 50 MB，画布像素总量限制为约 1920 x 1080，动态缩放使用低开销模式。
- GIF 加载或渲染失败时记录日志、移除本次背景并回退到主题背景，不影响代理核心。

## 外观入口与默认背景

- 顶部工具栏原三点按钮改为文字“外观”，弹层内“背景图片”位于“主题”上方。
- 背景配置从“设置 - 参数设置”迁移到独立“背景图片”窗口，保留选择、移除和透明度控制。
- 点击确定后保存配置并立即刷新首页和代理页；点击取消不修改当前背景。
- 新配置默认使用 `guiConfigs/default-workspace-background.gif`，默认透明度为 `100%`。
- 默认素材与用户素材分开管理：发布包只更新 `default-workspace-background.gif`；用户选择的图片保存为 `workspace-background.*`，升级不会覆盖用户图片或重新启用已移除的背景。
