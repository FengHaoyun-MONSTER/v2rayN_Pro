# 首页仪表盘 V2 设计说明

## 目标

首页以“一眼看懂当前是否可用”为核心，压缩低密度区域，同时保留自定义背景的可见面积。

## 布局

1. 顶部为全宽订阅摘要：订阅名称、总流量、剩余流量、已用流量、更新时间和到期时间。
2. 下方左侧为网络状态，约占 40% 宽度。
3. 下方右侧为服务公告，约占 60% 宽度。
4. 主窗口最小宽度下保持双列稳定，不允许文字或按钮互相遮挡。

## 网络状态

- 面板保持中性半透明背景，不使用大面积状态色。
- 状态色只用于左侧强调线、状态圆点和网络图标。
- 展示现有状态消息、活动节点、最近一次缓存真延迟和系统代理模式。
- “一键设置网络”和“联系客服”继续复用已有命令。

## 服务公告

- 公告正文在固定高度内滚动。
- “点我有惊喜”继续使用订阅返回的支持链接。

## 数据与行为边界

- 活动节点读取 `Config.IndexId` 对应的现有配置。
- 延迟读取 `ProfileExManager` 已有测速缓存，不触发额外测速。
- 系统代理状态读取现有 `SystemProxyItem`，并跟随 `StatusBarViewModel` 状态刷新。
- 本次改动不修改首次安装、订阅更新、真延迟测试、自动排序、活动节点选择、系统代理设置或网络修复流程。
