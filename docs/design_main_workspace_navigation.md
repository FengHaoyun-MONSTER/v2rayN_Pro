# 主窗口首页/代理导航设计

## 目标

在主窗口顶部“配置项”左侧增加“首页”和“代理”两个互斥导航按钮：

- 首页：全宽显示当前订阅、服务公告、剩余流量、剩余天数和到期时间。
- 代理：全宽显示节点管理区域及日志、代理、连接视图。
- 首次启动默认显示首页，后续启动恢复用户最后停留的页面。
- 删除原“隐藏首页”和“展开首页”入口。

## 无感切换

主窗口启动时分别创建一次首页与代理工作区的 View 和 ViewModel。页面切换只修改两个常驻工作区的 `Visibility`，不重新创建控件、不重新读取数据库，也不触发节点或日志刷新。

因此切换前后的以下状态保持不变：

- 当前订阅分组、节点选择和过滤条件。
- 节点列表及日志滚动位置。
- 日志、测速、订阅更新和 CloudflareST 优选任务。
- 代理页内部的分隔条尺寸和标签页选择。

## 布局兼容

首页始终全宽。代理工作区继续使用设置中已有的 `MainGirdOrientation`：

- Horizontal：节点列表与日志左右排列。
- Vertical：节点列表与日志上下排列。
- Tab：节点列表、日志、代理和连接使用标签页。

导航方式在三种代理布局中保持一致，不废弃用户已有布局设置。

## 状态保存

在 `UIItem` 中增加 `MainWorkspacePage`，取值为 `Home` 或 `Proxy`，默认 `Home`。点击导航按钮时先同步切换界面，再异步保存配置，确保视觉切换不受磁盘写入影响。

## 旧逻辑清理

移除以下内容：

- 首页内的“隐藏首页”按钮。
- 节点工具栏内的“展开首页”按钮。
- `SubscriptionDashboardVisibilityChanged` 事件。
- 通过调整首页列宽实现展开/折叠的逻辑。

## 添加订阅入口

- 顶部导航顺序为“首页、添加订阅、代理”。
- 代理工具栏不再重复显示“添加订阅”。
- 顶部按钮通过 `AppEvents.AddSubscriptionRequested` 调用与现有 `ProfilesViewModel.AddSubCmd` 共用的新增订阅流程。
- 订阅弹窗、自动选中新分组、自动更新、自动测速和延迟排序逻辑均不修改。
