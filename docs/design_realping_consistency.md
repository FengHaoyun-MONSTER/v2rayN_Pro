# v2rayN 真延迟一致性说明

## 列表延迟

节点列表“延迟测试”按钮显式使用 `ESpeedActionType.Realping`，并保持测试当前分组全部节点。测速服务为每个节点启动本地代理端口，通过该端口请求配置的真延迟测试 URL。

自动更新订阅后的延迟测试同样显式使用 `Realping`，随后继续执行不可用节点清理、延迟排序和活动节点设置。

## 当前延迟

底部状态栏“当前延迟”通过当前活动节点的本地 SOCKS 代理请求相同的真延迟测试 URL，调用 `ConnectionHandler.GetRealPingTime`。

列表延迟与当前延迟最终复用同一个 HTTP 真延迟实现。两次数值可能因测试时间、连接预热、网络抖动和并发状态不同而存在差异，但不存在 TCPing 与 Realping 混用。
