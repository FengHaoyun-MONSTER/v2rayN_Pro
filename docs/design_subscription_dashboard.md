# v2rayN 订阅信息面板设计

## 目标

在 Windows 默认主窗口中增加当前订阅的信息面板，并保持节点管理与运行日志的使用效率。

主窗口采用以下结构：

- 左侧：当前订阅名称、服务公告、剩余流量、剩余天数、到期时间、最后更新时间。
- 右上：原节点列表及其全部操作。
- 右下：原日志、代理和连接视图。
- 底部：原状态栏，行为不变。

左右和右侧上下区域均保留可拖动分隔条。右侧上下高度继续使用原有配置保存。

## 数据来源

订阅更新时读取主订阅 HTTP 响应头，并持久化到 `SubItem`：

| 响应头 | 用途 |
| --- | --- |
| `subscription-userinfo` | `upload`、`download`、`total`、`expire` |
| `announce` 或带前缀的 `*-announce` | 服务公告 |
| `profile-web-page-url` | 服务商主页，保留供后续交互使用 |
| `support-url` | 客服地址，保留供后续交互使用 |

响应头名称不区分大小写，并使用后缀匹配，兼容服务商增加自定义前缀的情况。公告支持普通文本、`base64:` 文本和 `\n` 换行。

## 展示规则

- 剩余流量：`total - upload - download`，最低显示为零，并固定使用 GB（`1024^3` 字节）作为单位。
- `total` 不存在或小于等于零：显示 `∞`。
- 到期时间为 Unix 秒时间戳，并转换为本地时间。
- `expire` 不存在或小于等于零：剩余天数显示 `∞`，到期时间显示“永久”。
- 未选择具体订阅或选择“全部”分组：显示引导空状态。
- 响应头缺失或格式错误不会中断订阅更新，继续保留上一次有效信息。

## 刷新链路

1. 用户切换订阅分组时发布当前订阅 ID。
2. 左侧面板读取对应 `SubItem` 并刷新。
3. 订阅更新成功后保存响应头数据并发布订阅刷新事件。
4. 左侧面板立即显示最新流量、公告和到期信息。

## 兼容性

该界面应用于 WPF Windows 客户端的默认 `Vertical` 布局。原 `Horizontal` 和 `Tab` 布局保持原样，避免改变用户主动选择的其他工作区布局。

## 首页显示状态

- 首次启动默认展开订阅首页。
- 展开时左侧面板右上显示“隐藏首页”。
- 隐藏后节点工具栏最左侧显示“展开首页”，节点和日志区域自动占满窗口宽度。
- 每次点击后立即保存 `UIItem.ShowSubscriptionDashboard`，下次启动恢复上一次状态。
