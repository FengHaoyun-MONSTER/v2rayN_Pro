# v2rayN 订阅信息面板设计

## 目标

在 Windows 默认主窗口中增加当前订阅的信息面板，并保持节点管理与运行日志的使用效率。

主窗口采用以下结构：

- 首页顶部：当前订阅名称，右侧显示最后更新时间和到期时间。
- 首页中部：自适应高度的服务公告，右上提供“点我有惊喜”入口。
- 首页底部：共有流量、剩余流量和已用流量。
- 代理页：原节点列表、日志、代理和连接视图。
- 底部：原状态栏，行为不变。

代理页内部原有可拖动分隔条继续保留，其尺寸仍使用原配置保存。

## 数据来源

订阅更新时读取主订阅 HTTP 响应头，并持久化到 `SubItem`：

| 响应头 | 用途 |
| --- | --- |
| `subscription-userinfo` | `upload`、`download`、`total`、`expire` |
| `announce` 或带前缀的 `*-announce` | 服务公告 |
| `profile-web-page-url` | 服务商主页，保留供后续交互使用 |
| `support-url` | 客服地址，保留供后续交互使用 |

`support-url` 存在且为合法的 `http`、`https` 或 `tg` 绝对链接时显示“点我有惊喜”，点击后交给系统默认程序打开。

响应头名称不区分大小写，并使用后缀匹配，兼容服务商增加自定义前缀的情况。公告支持普通文本、`base64:` 文本和 `\n` 换行。

## 展示规则

- 共有流量：`total`；已用流量：`upload + download`；剩余流量：`total - upload - download`，最低显示为零，并固定使用 GB（`1024^3` 字节）作为单位。
- `total` 不存在或小于等于零：显示 `∞`。
- 到期时间为 Unix 秒时间戳，并转换为本地时间。
- `expire` 不存在或小于等于零：到期时间显示“永久”。
- 未选择具体订阅或选择“全部”分组：显示引导空状态。
- 响应头缺失或格式错误不会中断订阅更新，继续保留上一次有效信息。

## 刷新链路

1. 用户切换订阅分组时发布当前订阅 ID。
2. 左侧面板读取对应 `SubItem` 并刷新。
3. 订阅更新成功后保存响应头数据并发布订阅刷新事件。
4. 左侧面板立即显示最新流量、公告和到期信息。

## 兼容性

首页在三种代理布局下均保持全宽。代理页继续尊重原 `Horizontal`、`Vertical` 和 `Tab` 布局设置。

## 首页导航

- 主窗口顶部通过“首页”和“代理”两个按钮切换全宽工作区。
- 首次启动默认显示首页，后续启动恢复上次停留的工作区。
- 首页和代理视图在窗口启动时各创建一次，切换可见性时不重新加载数据。
- 详细实现见 `design_main_workspace_navigation.md`。

## 紧凑流量布局

- 首页删除独立流量统计板块，将共有、剩余、已用流量放在“当前订阅”后方。
- 首页继续保留订阅名称、更新时间、到期时间和服务公告，原数据绑定与刷新机制不变。
- 代理页仅在当前选中项是真实订阅时，于订阅名称下方显示小字号流量摘要。
- 选择“所有”或普通非订阅分组时隐藏流量摘要，不计算跨订阅汇总。
