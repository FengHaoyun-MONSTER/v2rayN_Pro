# 订阅编辑弹窗紧凑模式设计

## 目标

降低新增订阅时的填写成本，默认只突出最常用的订阅链接输入框，同时保留原有全部高级配置。

## 界面结构

- 第一项固定为“可选地址 (Url)”。
- URL 右侧保留原“更多地址”菜单。
- 新增 `∨` 按钮用于展开高级设置，展开后切换为 `∧`。
- 高级设置中的第一项为“别名”，其余字段顺序保持不变。
- “确定”和“取消”按钮始终显示。
- 默认窗口使用紧凑高度；展开时恢复原完整高度，折叠时再次收缩。

## 保存行为

- 用户只填写订阅链接即可保存。
- 别名为空且 URL 有效时，先使用 URL 的主机名作为别名并标记为自动别名。
- 订阅更新返回 `profile-title` 时，自动别名替换为配置标题；兼容普通文本和 `base64:` 标题。
- 用户手动填写或修改过的别名不会被订阅更新覆盖。
- URL 和别名都为空时，仍提示用户填写别名，保持普通空分组的原有校验。
- 所有折叠字段仍正常参与数据绑定和保存，不会因折叠丢失已有设置。

## 兼容性

本次界面调整应用于 Windows WPF 客户端。订阅保存逻辑位于共享 `ServiceLib`，因此自动生成别名的行为对所有客户端一致。
